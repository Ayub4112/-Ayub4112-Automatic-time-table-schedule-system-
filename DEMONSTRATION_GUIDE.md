# ATSS Demonstration Guide

## Option A: Open directly

Double-click `standalone-demo/index.html`.

## Option B: Run with a small local server

### Windows

Double-click `start-demo.bat`, then visit `http://localhost:8080`.

### macOS or Linux

Run:

```bash
./start-demo.sh
```

Then visit `http://localhost:8080`.

## Login credentials

- Administrator: `admin@vu.ac.ug` / `admin123`
- Lecturer: `lecturer@vu.ac.ug` / `lecturer123`
- Student: `student@vu.ac.ug` / `student123`

The Administrator role can create and edit academic records, manage stock, monitor low-stock items, generate the timetable, inspect conflicts, export the timetable, and view reports. Lecturer and Student roles display restricted personalised information.
